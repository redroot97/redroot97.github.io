disclosure policy

// how I report
[ step 01 ]
Private Report
Findings sent directly to the vendor's security team via PSIRT, security.txt, or HackerOne / Bugcrowd / private programs. PGP-encrypted when supported.
[ step 02 ]
Coordinated Timeline
Standard 90-day window for vendor remediation. Extensions granted when patches are in flight. Earlier disclosure if exploitation is observed in the wild.
[ step 03 ]
Public Advisory
Once patches ship, a CVE is assigned and a detailed write-up - including reproduction steps and impact analysis - is published on this site and linked here.
